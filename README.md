# Soil-Monitoring-System
This project began with a simple idea: make soil conditions easier to understand through a portable monitoring device. Soil moisture and nutrient levels are not always visible, yet they influence decisions about watering, fertilizer use, and crop care. The aim was to bring these measurements together in one practical embedded system.
The system uses an ESP32 and a 7-in-1 soil sensor to measure soil moisture, temperature, electrical conductivity (EC), pH, nitrogen, phosphorus, and potassium. The sensor communicates with the ESP32 through an RS-485 interface using Modbus RTU. An OLED display presents the readings locally, allowing users to check soil conditions directly in the field.
Development involved connecting the sensor, implementing Modbus requests, decoding the returned data, and displaying the measurements clearly. Testing also involved troubleshooting communication timeouts and checking how the readings changed under different soil conditions. This provided hands-on experience in embedded programming, sensor integration, serial communication, and hardware debugging.
The prototype was tested in field to demonstrate its operation in a practical setting. It provides a foundation for future improvements such as wireless monitoring, historical data logging, a mobile dashboard, and irrigation alerts. With further calibration and validation of the sensor readings, the system could help users make more informed soil management decisions.
